# CHANGELOG

## 0.9.0 — 20.11.2026
- Исходники проекта извлечены из архива и размещены в корне репозитория.
- Render backend теперь имеет ожидаемый путь `backend/Dockerfile`.
- Android versionName/versionCode обновлены до 0.9.0/9.
- Добавлена поддержка типовых PostgreSQL URL Render с psycopg v3.
- Добавлены production-проверки обязательных секретов.
- Публичный каталог не раскрывает URL потоков Premium-карточек.
- GitHub Actions собирает APK непосредственно из дерева исходников.

# MOVNET — список изменений

## Версия прототипа 0.3 (этапы 2–8, частичная реализация)

### 2. Страницы контента
- Сохранены карточки фильмов и сериалов, описания, выбор сезона и серии.

### 3. Видеоплеер
- Добавлен AndroidX Media3 ExoPlayer.
- Добавлен экран воспроизведения и тестовый MP4-поток Big Buck Bunny от Blender Foundation.

### 4. Аккаунты
- Добавлен экран профиля и демонстрационный вход по email.
- Это локальный UI-прототип: настоящая регистрация, пароль, подтверждение почты и серверная сессия отсутствуют.

### 5. Подписки и Premium
- Сохранены четыре тарифных карточки и заявленные цены.
- Серверная проверка Premium и выдача entitlement не реализованы; UI не является защитой контента.

### 6. Telegram и платежи
- Добавлена backend-документация с безопасным потоком платежей и одноразовых кодов.
- Бот, СБП, Telegram Stars, криптоплатежи и webhook не подключены: требуются merchant-аккаунты, токены и провайдер.

### 7. Реклама
- В плеере показано место под рекламную интеграцию.
- Рекламный SDK/IMA, рекламный сервер и фактические рекламные показы не подключены.

### 8. Загрузки
- Добавлена загрузка тестового MP4 в папку Downloads средствами Android DownloadManager.
- Это не защищённое офлайн-хранилище; подписочная блокировка, DRM и лицензии офлайн-контента не реализованы.

## Важно
Каталог и описания демонстрационные. Используйте только видео, на которые у вас есть права или разрешение на распространение. Нельзя ретранслировать чужие каталоги по одной лишь личной подписке на сторонний сервис.

## Версия прототипа 0.4 — избранное
- Добавлено добавление и удаление материалов из избранного по значку-сердцу.
- Вкладка «Избранное» теперь показывает только отмеченные карточки.
- Состояние избранного пока хранится в памяти приложения и сбрасывается после полного закрытия; постоянное хранение и синхронизация с аккаунтом требуют DataStore/backend.
- Остальные функции оплаты, Telegram и онлайн-каталога не объявляются готовыми: для них необходимы сервер, настройки провайдера и тестовые данные.


## Проверка и исправления после ревизии
- Исправлена прокрутка экрана Premium: все четыре тарифных карточки доступны на небольших экранах.
- Исправлен обход демонстрационного Premium-доступа через список серий: Premium-серии теперь ведут к экрану тарифов, а не запускают плеер.
- Уточнены подписи о демонстрационных видеопотоках и необходимости подключать лицензированные ролики.
- Сборка APK не подтверждена: в архиве по-прежнему отсутствует Gradle Wrapper, а Gradle/Android SDK в текущей среде не установлены.


## Версия 0.5 — backend аккаунтов и подписок (первый этап)
- Добавлен FastAPI backend и Docker-конфигурация с PostgreSQL.
- Регистрация и вход: Argon2id для паролей, JWT access token.
- Добавлены `/me` и серверный `/entitlements`.
- Добавлено одноразовое погашение кодов: в базе хранится хеш, повторное применение отклоняется.
- Платежный endpoint возвращает 501 до подключения реального провайдера; оплата не имитируется.
- Android-клиент пока не подключён к API; потребуется HTTPS URL развернутого сервера.


## v0.5.1 — проверка и подготовка CI
- Исправлена обработка дат истечения подписки при использовании SQLite.
- Явно установлены Java/Kotlin JVM target 17.
- Удалены `__pycache__` и добавлены правила `.gitignore`.
- Добавлена инструкция по сборке debug APK через GitHub Actions с Android-телефона.
- Android-клиент ещё не интегрирован с backend API.


## 0.5.2 — 20.11.2026
- Улучшен экран выбора Premium: четыре тарифа явно выбираются, состояние выбора отображается в карточке.
- Нажатие на тариф показывает, что оплата пока не подключена; фиктивная кнопка без действия убрана.
- Обновлён отчёт проверки архива: backend FastAPI присутствует, но Android-интеграция и платежи ещё не реализованы.

## 0.6.0 — 2026-11-20
- Added persistence for the favorites list using Android SharedPreferences; favorites survive app restarts.
- Removed the unrestricted sample-video download action. The UI now clearly states that offline downloads require an active Premium subscription, which cannot be activated until payments and server verification are connected.
- Added a repository-root GitHub Actions workflow that builds a debug APK and uploads it as `MOVNET-APK`.
- Updated mobile build instructions and project status documentation.
- Bumped Android versionCode to 6 and versionName to 0.6.0.
- Payment provider, Telegram bot, deployed backend, real licensed catalog and server-side Premium enforcement remain intentionally unconfigured.

## 0.7.0 — серверные аккаунты и каталог
- Подключены Android-экраны регистрации и входа к `/auth/register` и `/auth/login`.
- Access token сохраняется локально; профиль восстанавливается через `/me`, выход удаляет токен.
- Каталог приложения загружается из FastAPI endpoint `/catalog`.
- Добавлена таблица `catalog_items`, автоматическое заполнение демонстрационными карточками и защищённый ключом endpoint `POST /admin/catalog`.
- Добавлена настройка HTTPS API URL через Gradle property и GitHub Actions repository variable `MOVNET_API_BASE_URL`.
- Оплата, реальные видеопотоки и продакшен-администрирование пока не входят в этот этап.

## Версия 0.8.0 — тестовые MP4-потоки
- Каталог API теперь передаёт приложению поле `stream_url`.
- Для трёх демонстрационных карточек добавлены отдельные публичные MP4-примеры: Big Buck Bunny, Elephants Dream и Sintel.
- Android-плеер воспроизводит ссылку конкретной карточки, а не один и тот же жёстко заданный ролик.
- Если у карточки нет HTTPS-ссылки, приложение показывает понятное сообщение вместо запуска чужого тестового ролика.
- При старте backend заполняет тестовыми ссылками только пустые `stream_url` у трёх стартовых карточек; уже настроенные ссылки не перезаписываются.
- Тестовые ролики не являются содержимым вымышленных карточек и не заменяют лицензии на коммерческие фильмы.
- Версия Android-приложения повышена до 0.8.0 (versionCode 8).
- Backend проверен компиляцией Python; APK-сборка в этой среде не запускалась, так как Gradle/Android SDK отсутствуют.
