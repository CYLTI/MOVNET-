# MOVNET 0.7.0 — инструкция

## Что появилось
- Реальная регистрация и авторизация через backend по email и паролю.
- Пароль передаётся только по HTTPS; backend хранит Argon2id-хеш, а не исходный пароль.
- JWT access token сохраняется локально в SharedPreferences; при следующем запуске приложение проверяет профиль через `/me`.
- Кнопка выхода удаляет сохранённый токен.
- Каталог загружается с сервера из таблицы `catalog_items`, а не из локального списка Kotlin.
- Администратор может добавлять карточки через закрытый endpoint `POST /admin/catalog`.

## Перед сборкой APK
1. Сначала разверните `backend` по инструкции `backend/README.md`.
2. Установите GitHub Actions repository variable `MOVNET_API_BASE_URL` со своим HTTPS API URL.
3. Загрузите содержимое папки `MOVNET` в корень репозитория.
4. Откройте вкладку Actions и дождитесь завершения `Build MOVNET APK`.
5. Откройте успешный запуск workflow → Artifacts → `MOVNET-APK`.

Если backend ещё не развернут, авторизация и серверный каталог не смогут подключиться. APK может собраться, но приложение покажет ошибку соединения. Текущие карточки — демонстрационные, видеоплеер пока использует тестовый поток. Реальные видео, права на контент, постеры и управление сериями — отдельный следующий этап.
